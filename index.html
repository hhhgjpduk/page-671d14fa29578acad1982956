使用场景

跨境办公与远程协作

访问海外文档、代码仓库、会议工具时，可选用延迟较低的香港、日本或新加坡节点，并结合客户端分流，仅对指定域名走加速，本地办公流量保持直连。

学术检索与资料下载

需要查阅国际期刊、预印本或开发者文档时，机场订阅可提供多区域出口。建议为学术站点单独建立规则，避免与视频流量争抢带宽。

流媒体观看

基础版覆盖常见基础解锁；旗舰版与团队版强调原生流媒体。实际播放仍取决于节点质量与平台风控，遇到地区限制时可切换同区域备用节点。

国际游戏与语音

旗舰版标注 IPLC 游戏优化，适合对延迟敏感的对战与语音场景。团队版高带宽节点更利于更新下载与多人同时在线。

多设备家庭或小团队

按套餐设备上限分配手机、电脑与路由器。路由器导入订阅后，家里多台终端可共享同一机场能力，仍需注意总流量消耗。

操作说明

从官网到成功连上

  1. 在 GLaDOS 官网选择基础版、旗舰版或团队版并完成订阅。
  2. 登录用户中心复制机场订阅链接（通常为 Clash / 通用订阅格式）。
  3. 安装对应系统的客户端，将订阅粘贴到「配置 / Profile / 订阅」栏并更新。
  4. 开启系统代理或 TUN 模式，先选延迟较低的节点测试连通，再按规则分流。
  5. 流媒体与游戏请优先使用套餐说明中的专线或原生解锁节点，并观察流量余量。

客户端选择建议

Windows、macOS、Linux 常用 Clash Meta / Clash Verge 或 sing-box 图形客户端。iOS 常用 Shadowrocket、Stash 或 Quantumult X。Android 常用 Clash Meta for Android。路由器可使用支持订阅的固件导入同一链接。

GLaDOS 以订阅为核心，并不绑定单一封闭 App。把官方订阅导入你熟悉的客户端，即可获得节点列表与自动更新。

节点、性能与安全说明

节点池覆盖香港、台湾、日本、韩国、新加坡、美国及欧洲等常用方向。普通线路适合网页与日常通讯；旗舰版 IPLC 与团队版 VIP 高带宽更偏向游戏与大流量传输。延迟受本地宽带、运营商与时段影响，连接后可在客户端按延迟排序。

传输使用常见加密代理协议。请只从 GLaDOS 官网获取订阅，不要在公共群组长期使用他人分享链接。流量按套餐额度计量并按月重置，多设备共享同一额度。

常见问题

GLaDOS 是什么？和普通 VPN 有什么区别？

GLaDOS 提供机场订阅：一份链接对应一组可切换节点，在第三方客户端里使用。普通 VPN 往往是单一 App 与固定线路。机场更适合需要分流规则、多地区出口和自选客户端的用户，GLaDOS 同时给出明确套餐档位，降低选择成本。

如何在官网完成订阅并下载配置？

打开 GLaDOS 官网，对比基础版、旗舰版、团队版后付款。进入用户中心复制订阅地址，粘贴到客户端的订阅栏并更新。这就是最主要的「官方下载」步骤：下载的是配置与节点，而不是必须绑定某一品牌安装包。

支持哪些设备？会不会超设备数？

电脑、手机、平板和部分路由器都可导入同一订阅。基础版约 3 台、旗舰版约 5 台、团队版约 20 台同时在线。超过上限时可能被踢下线，家庭共用建议走路由器或升级档位。

流量如何计算？用完或到期怎么办？

流量按套餐额度统计，一般按月重置。当月用尽需等待重置或升级。订阅到期后节点不可用，续费后恢复。年付套餐价格更低，适合长期把 GLaDOS 当作主力加速器的用户。

能否解锁流媒体？ChatGPT 一类服务呢？

基础版标注基础流媒体；旗舰版与团队版强调全节点原生解锁，覆盖常见影视平台。部分 AI 与网站对数据中心 IP 敏感，遇到验证时可换住宅或同区域节点。效果随平台策略变化，不能理解为永久保证。

游戏延迟高怎么办？IPLC 怎么用？

优先选用旗舰版中的 IPLC 游戏优化节点，并关闭占用带宽的下载任务。用客户端延迟测试排序，避开晚高峰拥挤线路。团队版高带宽更适合更新包。本地 Wi-Fi 质量同样影响体感。

安全吗？会不会有日志？订阅泄露怎么办？

请只使用官网订阅并开启客户端加密。服务侧通常以不记录上网日志为宣传原则，但设备本身仍要避免安装来路不明插件。若订阅意外泄露，应立即在官网重置链接并更新所有客户端。
